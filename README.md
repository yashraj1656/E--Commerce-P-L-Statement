# E--Commerce-P&L-Statement
📊 Financial Performance & Balance Sheet Analysis Dashboard (Power BI)
📌 Project Overview

This project is a comprehensive Power BI financial analytics dashboard designed to analyze and compare the performance of multiple companies using Profit & Loss and Balance Sheet data.

The objective of this dashboard is to transform complex financial statements into interactive visual insights that support better decision-making and comparative business analysis.

🎯 Business Objective

Organizations often struggle to interpret raw financial tables quickly. This project aims to:

Convert financial statements into visual analytics

Compare company performance across key profitability metrics

Identify trends, strengths, and weak areas

Enable decision-makers to analyze KPIs efficiently

📂 Project Modules

1️⃣ Profit & Loss Analysis

Revenue from Operations

Gross Margin

Operating Profit

Profit Before Tax (PBT)

Profit After Tax (PAT)

Expense & Cost Analysis

2️⃣ Dashboard Visualization

Interactive visual analytics including:

KPI Cards (Gross Margin %, Operating Profit %, PBT %, PAT %)

Bar Charts for Company Comparisons

Trend Line Analysis

Performance Subtotal Analysis

Percentage-Based Financial Comparison

3️⃣ Balance Sheet Analysis

Non-current Assets

Current Assets

Investments

Cash & Equivalents

Equity & Liabilities

Year-over-Year Financial Comparison

📊 Key Insights Delivered

Comparative profitability analysis between multiple companies

Visualization of margin performance trends

Financial health monitoring through the balance sheet structure

Easy identification of high and low-performing entities

🛠️ Tools & Technologies

Power BI Desktop

Power Query (Data Cleaning & Transformation)

DAX (Measures & KPI Calculations)

Financial Statement Data (P&L + Balance Sheet)
